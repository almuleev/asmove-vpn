# Сообщения об уязвимостях

Это предварительная версия без обещанного SLA исправлений. Поддерживается только
текущая версия. Не используйте реальные аккаунты/серверы других людей для проверки.

После публикации используйте GitHub → Security → Advisories → Report a vulnerability
в этом репозитории. Владелец должен включить Private vulnerability reporting **до
публичного запуска**. Пока репозиторий не создан, публичного приватного канала нет;
не создавайте публичный issue с секретами. Контакт владельца не выдуман.

Передайте минимальное воспроизведение на тестовых данных, затронутый commit,
влияние и предложенное исправление. Если канал недоступен, запросите у владельца
приватный способ связи без раскрытия деталей. Сначала отзовите скомпрометированные
токены/ключи, затем передавайте очищенные данные. [Хранение и отзыв](docs/OPERATIONS.md).

Модель доверия: root RU управляет EU через SSH и имеет токен удаления/заказа VPS;
компрометация RU затрагивает оба узла. Web работает отдельным пользователем,
контрольные SSH-ключи закрыты root. HTTPS обязателен, подписка — секрет доступа.
TOFU первого контакта при последующих заказах описан в README; строгий ручной
fingerprint gate используется при подключении первого EU.
