# Установка для новичка

Это инструкция для владельца двух новых серверов. Мастер выполняет настройку;
уметь программировать не нужно. Он пока не проверен на реальном чистом VPS,
поэтому перед постоянным использованием нужна приёмка на собственных серверах.

## Что купить

**Первый сервер — в России (RU).** В кабинете хостинга выберите создание VPS,
локацию в РФ, Ubuntu 24.04 LTS x86_64/amd64, публичный IPv4 и root SSH. Рекомендуем
2 vCPU, 2 ГБ RAM, 20 ГБ диска. Цену посмотрите у своего хостинга.

**Второй — за рубежом (EU).** Зарегистрируйтесь в VDSina.com, пополните USD-баланс,
создайте VPS с чистой Ubuntu 24.04 amd64 на фиксированном тарифе **$0.07/сутки**.
Готовую панель 3x-ui в образе не выбирайте. Если точный тариф/ОС недоступны,
остановитесь: другой тариф эта версия не поддерживает.

В обоих кабинетах сохраните доступ к web/VNC-консоли. Это окно управления сервером
в браузере; оно поможет, если SSH перестанет работать. Узнайте публичные IPv4 обоих VPS.

## Подключиться к RU

В web-консоли RU выполните `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256`.
Это отпечаток сервера, а не секрет. На Windows откройте PowerShell; на macOS/Linux —
Terminal. Замените REPLACE_RU_IPV4 своим адресом:

```text
ssh -o HostKeyAlgorithms=ssh-ed25519 root@REPLACE_RU_IPV4
```

Сравните показанный SHA256 с отпечатком из консоли, подтвердите `yes` только при
совпадении. Введите пароль root от хостинга: символы не отображаются. Если сервер
настроен на ваш SSH-ключ, укажите его через `-i`. Ожидается строка `root@...`.
Нет ssh/timeout/Permission denied? См. [подключение и диагностику](INSTALL.md#2-подключиться-с-компьютера).

## Запустить мастер — на RU

Теперь команды выполняются в открытом SSH к RU, **не прямо в PowerShell**:

```bash
apt-get update
apt-get install -y git python3 ca-certificates
git clone https://github.com/almuleev/asmove-vpn.git /opt/asmove-src
cd /opt/asmove-src
python3 deploy/setup.py
```

Мастер установит кабинет на RU. Дальше он по очереди попросит:

1. **IPv4 RU.** Адрес российского сервера.
2. **Добавить публичный SSH-ключ.** Скопируйте показанную строку `ssh-ed25519 ...`
   в VDSina → SSH Keys. На уже созданном EU добавьте её также через web-консоль в
   `/root/.ssh/authorized_keys`: `install -d -m 700 /root/.ssh`, затем
   `nano /root/.ssh/authorized_keys`, вставьте строку и сохраните; выполните
   `chmod 600 /root/.ssh/authorized_keys`. Приватный ключ с RU переносить не нужно.
3. **IPv4 EU.** Адрес зарубежного сервера.
4. **Отпечаток EU.** В web-консоли EU выполните
   `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256`, скопируйте часть
   `SHA256:...`. Не берите отпечаток только из непроверенного ssh-keyscan.
5. **API-токен VDSina.com.** В панели откройте информацию пользователя/раздел API,
   скопируйте постоянный токен. Ввод скрыт. Не вставляйте токен в чат/issue/команду.
6. **ОС и площадку будущих замен.** Выберите варианты из списка. ID сервера,
   тарифа, ОС и SSH-ключа мастер найдёт сам и проверит через API.
7. **Режим восстановления.** Для автоматического удаления/заказа после сбоя введите
   `ДА`. Пустой ответ оставляет ручное подтверждение. Правила можно изменить позже.

До запуска firewall RU должен разрешать 22 от вас, 80 для сертификатов, 443 для
кабинета; EU — 22 с RU и от вас, 80 для сертификатов, TCP 443 и 2053 для VPN.
Не открывайте внутренний порт 8016 или web-порт 3x-ui. Если есть внешний firewall,
изменяйте его в своём кабинете хостинга; мастер его не сбрасывает.

Ожидается `ready: true`, `vpn_verified: true`. Мастер не арендует и не удаляет
VPS во время первоначальной установки. Если он остановился, сохраните вывод без
секретов, исправьте причину и повторите ту же команду. Не удаляйте базы/конфиг и
не запускайте bootstrap с новым IP ради обхода ошибки. [Диагностика](DIAGNOSTICS.md).

## Создать пользователя и подключить устройство

На RU в приватной консоли: `cat /etc/access-site/initial-admin.txt`.
На компьютере откройте `https://ВАШ_RU_IP/admin` без предупреждения TLS, войдите
паролем из файла. Создайте пользователя, сохраните его шестисимвольный код.

Откройте `https://ВАШ_RU_IP/`, войдите кодом, нажмите «Копировать ссылку подписки».
Добавьте её в приложение с поддержкой VLESS XHTTP/TLS как **подписку по URL**,
обновите, выберите Connection и включите VPN. Windows: v2rayN; Android: v2rayNG.
Ссылки на официальные приложения и шаги есть в кабинете и в [INSTALL](INSTALL.md).

Проверьте открытие сайтов через VPN. Затем проверьте отзыв доступа тестового
пользователя в админке. Не выключайте TLS-проверку ради соединения.

## После установки

В админке → Серверы и замены видно проверки и правила [автовосстановления](AUTOMATION.md).
Вначале можно оставить ручной режим, проверить подписку и backup, затем включить
автоматику с согласием на простой. Telegram, ntfy и другие дополнительные функции
не нужны для первого подключения. [Создайте внешнюю резервную копию](OPERATIONS.md).

После замены EU URL подписки остаётся прежним: обновите подписку и переподключитесь.
Прямой URI со старым IP импортируется заново. Потеря самого RU — отдельное восстановление.
