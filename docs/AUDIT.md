## Найденные расхождения и исправления

- В README исходника действующий bootstrap назывался самостоятельным, но имел
  default origin существующего Pages. Новый default — встроенный RU-кабинет,
  origin статического кабинета задаётся владельцем явно.
- Документация публикации советовала править константу в старом replace-vps,
  содержащем также старые сценарии реплик. Он исключён; новый build-portal имеет
  явный --api-origin, не ходит в сеть и не выполняет замену VPS.
- launcher/test.mjs исходника импортировал архивный legacy-launcher.js. В новом
  проекте тестируются текущие функции кабинета без архива.
- Из install/update исключён перенос старых units и частный IP relay. Обновление
  доставляет только отобранные root scripts и units; обещание отката ограничено web.
- Расчёт RUB для исторического аудита остаётся внутренним, refresh-costs и таймер
  CBR не включены: заказ проверяет нативные USD 0.07. Месячные бюджеты не добавлены.
- Vdsina из исходника допускал .ru и .com при числовой цене. Новая версия отклоняет
  .ru, чтобы 0.07 в иной валюте не трактовалось как USD.
- Скриншоты в исходных guide HTML ссылались на изображения с неизвестной приватностью.
  Изображения исключены; текстовые инструкции сохранены, ссылки загрузки ведут
  на официальные releases. Добавлены собственный вектор и явно вымышленная demo-карточка.
- Целевой runtime — Python 3.12 на Ubuntu 24.04; отдельные remote-функции используют
  hashlib.file_digest и tarfile filter, поэтому нижняя граница Python 3.10 в старом
  install.sh недостаточна. Новый установщик требует 3.12.

Что работает по коду/тестам: auth/CSRF, подписки, согласованная публикация, preflight,
журнал намерения, сверка неизвестного заказа, backup integrity и сохранение клиентов.
Что не доказано локально: установка на VPS, реальные API-квоты .com, сетевой доступ,
первый заказ/удаление, продление сертификатов и приложения на устройствах.
После исходного импорта добавлены настройка автоматической замены, две HTTPS-цели
и мастер подключения серверов/API. Ручное подтверждение сохранено как отдельный
режим. Мастер ротации/удаления и автоматическая внешняя доставка backup не реализованы.
