Употребляемые пользователями формулировки: «не подключается», «не открываются
сайты», «SSH error», «wrong IP in config», «TLS handshake times out», «обновить
подписку». Это примеры языка обсуждений, не частотность поисковых запросов.
Русские поисковые формулировки «свой VPN на VPS», «VPN перестал работать»,
«замена IP VPN», «постоянная подписка VLESS» — гипотезы для будущей проверки.

## Что пока неизвестно

Из issues нельзя установить приемлемую для новичков цену двух VPS, готовность
обслуживать Linux, доверие к provider token, спрос на автоматический заказ или
долю пользователей, которым достаточно подписок. Численных оценок и отзывов нет.
Запросы на удобную установку и сохранение настроек видны качественно; вывод о
востребованности этой конкретной системы ещё требует проверки.

Гипотеза: пользователь охотнее доверит доступ, если видит код до запуска,
разделение web/root, точные API-операции, путь отзыва и подтверждение удаления.
Поэтому README сначала объясняет проблему, затем схему, расходы, риск root/token
и один маршрут. Страница не использует отзывы, вымышленные метрики или гарантии.

Для следующей проверки проведите 5–8 интервью и наблюдаемый проход INSTALL на
изолированных собственных VPS: где остановились, сколько готовы платить в месяц,
сколько времени тратить на обслуживание, доверят ли token, хотят ли подтверждать
удаление, понимают ли разницу URL подписки и URI. Это план, интервью не проведены.
