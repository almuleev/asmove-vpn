# Диагностика без случайного заказа VPS

Сначала фиксируйте: какая сеть, устройство/клиент, время, последний успешный вход,
есть ли свежий RU-отчёт. Удаляйте секреты из копий журналов. Используйте read-only
команды OPERATIONS; не запускайте worker как «проверку статуса».

| Симптом | Что проверить | Следующее действие |
| --- | --- | --- |
| SSH timeout | IPv4, статус VPS, порт 22, firewall | Консоль провайдера; не отключать host key checking |
| Host key changed | Переустановка/смена service ID | Сверить fingerprint через независимую консоль |
| TLS error | Время, SAN IP, chain, таймер и HTTP/80 | Исправить продление; не включать allowInsecure |
| 502 у кабинета | systemctl status access-site и журнал | Проверить env/venv/loopback; не заказывать EU |
| /health ok, сайты не открываются | Реальный запрос через Xray и клиентская маршрутизация | /health доказывает только web |
| Порт открыт, vpn_ok=false | Конфиг, сертификат, транспорт, цель HTTPS | TCP не доказывает работу VPN |
| observer_ok=false | Контрольная цель/сеть RU/запуск Xray | Не считать это подтверждённой неисправностью EU |
| RU ok, домашняя сеть нет | Другой согласованный тест с того же клиента/сети | Ограничение может быть локальным для провайдера/транспорта |
| Нет подписки после замены | Обновление URL в клиенте, auth_version, срок | Обновить подписку вручную и переподключиться |
| Прямой URI не работает | Он содержит старый EU IP | Скопировать новый из кабинета и импортировать заново |
| Ошибка создания пользователя | check-panel, SSH-туннель, полный набор inbound ID | Не обходить identity check |
| provider_balance_insufficient | Реальный баланс/min_money | Пополнить вручную; продолжать тот же job |
| provider_offer_unavailable / price mismatch | day, ровно 0.07, DC/шаблон/active | Не подставлять похожий тариф |
| uncertain / order_result_unknown | Журнал намерения и инвентарь VDSina | Не повторять POST и не создавать новый job |
| Telegram задержан | Состояние EU/SOCKS и очереди | ntfy независим; кабинет продолжает работать |
| Backup readiness failed | Свежесть архива, SSH backup key, SQLite integrity | Восстановить backup до удаления EU |

На EU команды сертификата:

```bash
systemctl status nodeguard-vpn-tls.timer --no-pager
journalctl -u nodeguard-vpn-tls.service -n 40 --no-pager
openssl x509 -in /etc/nodeguard-vpn-tls/fullchain.pem -noout -dates -ext subjectAltName
```

Одна HTTP-цель проверки может отказать независимо от VPN. Перед подтверждением
дорогой/необратимой операции проверьте другую HTTPS-цель через VPN и состояние
провайдера. Автоматической независимой классификации причин и нескольких целей
в стандартной установке пока нет. Белые списки мобильных сетей могут блокировать
и новые адреса; смена IP сама по себе не обещает восстановления.
