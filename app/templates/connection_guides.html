iPhone / iPad · V2RC
  1. Установите V2RC из App Store или откройте уже установленное приложение.
  2. В кабинете нажмите «Копировать ссылку подписки», затем перейдите в V2RC.
  3. На главном экране V2RC нажмите верхнюю строку с глобусом «Please import a config first». Если подключение уже добавлено, в этой строке будет его название.
  4. На экране Config List нажмите Import Config («Импортировать»). Если список уже заполнен, нажмите + справа сверху.
  5. На экране Import Config выберите Subscription. В поле Subscription Name введите название, например VPN Node Guard. В поле Subscription URL вставьте скопированную ссылку подписки. Нажмите внизу Import Subscription и дождитесь загрузки списка подключений.
  6. В списке Config List выберите подключение Connection.
  7. Вернитесь на главный экран стрелкой ‹ слева сверху, если он не открылся автоматически. Проверьте, что в верхней строке выбрано Connection. Нажмите большую круглую кнопку Tap to connect. При первом запуске разрешите iOS добавить конфигурацию VPN.
  8. Дождитесь надписи Internet OK и откройте любой сайт для проверки.

Android · v2rayNG

Инструкция для v2rayNG 2.3.15. В других версиях названия и расположение кнопок могут отличаться.

  1. Скачать v2rayNG для Android (APK). Откройте скачанный APK и установите приложение. Если v2rayNG уже установлен, просто откройте его.
  2. В кабинете нажмите «Копировать ссылку подписки». Перейдите в v2rayNG.
  3. Нажмите ☰ слева сверху → «Группы», затем + справа сверху.
  4. В поле «Название» введите VPN Node Guard. В поле «URL (необязательно)» вставьте скопированную ссылку подписки — для нашего способа это поле нужно заполнить.
  5. В этой же группе включите «Использовать обновление» и «Использовать автообновление». В поле «Интервал автообновления» укажите 60 минут. Нажмите галочку ✓ справа сверху для сохранения.
  6. Вернитесь на главный экран и выберите вкладку VPN Node Guard. Нажмите ⋮ справа сверху → «Обновить подписку». Если открылось окно с дополнительными действиями, оставьте включённым только обновление подписки и нажмите «ОК». Дождитесь появления подключений.
  7. Нажмите профиль Connection, затем кнопку запуска ▶ внизу справа. Подтвердите системный запрос Android на создание VPN-подключения, если он появится.
  8. Откройте сайт в браузере. В v2rayNG также можно нажать строку состояния внизу экрана для проверки текущего соединения.
  9. Автообновление в Android может задерживаться из-за фоновых ограничений. Если после замены сервера подключение не работает, вручную повторите ⋮ → «Обновить подписку» и подключитесь снова.

Windows · v2rayN
  1. Скачать v2rayN для Windows x64 (ZIP), распакуйте архив и запустите приложение от имени администратора. Если v2rayN уже установлен, откройте его от имени администратора.
  2. В кабинете нажмите «Копировать ссылку подписки». Перейдите в v2rayN.
  3. В верхнем меню нажмите Subscription Group.
  4. Выберите Subscription group settings («Настройки групп подписок»).
  5. В открывшемся окне нажмите + Add («Добавить»).
  6. В поле Remarks введите название группы, например nodeguard. В поле URL (optional) вставьте скопированную ссылку подписки. Оставьте Enable update включённым, а в Automatic update interval (minutes) задайте 60. Остальные поля менять не нужно. Нажмите Confirm и закройте окно настроек групп.
  7. В главном окне выберите вкладку созданной группы — в примере nodeguard рядом с All.
  8. Снова откройте Subscription Group и нажмите Update subscriptions without proxy. Дождитесь появления подключений в списке.
  9. Выберите подключение Connection и сделайте его активным: нажмите Enter или дважды щёлкните по строке.
  10. Внизу окна в меню Routing выберите вариант с (Global). Включите переключатель Enable Tun. Если потребуется, подтвердите запрос Windows; приложение должно быть запущено от имени администратора.
  11. Откройте сайт в браузере и проверьте доступ к интернету. После замены сервера обновляйте эту же подписку через Subscription Group → Update subscriptions without proxy. Повторно добавлять URL не нужно.

Windows · v2rayN
  1. Скачать v2rayN для Windows x64 (ZIP), распакуйте архив и запустите приложение от имени администратора. Если v2rayN уже установлен, откройте его от имени администратора.
  2. Нажмите «Копировать ссылку подключения». Вернитесь в v2rayN.
  3. В верхнем меню нажмите Configuration → Import Share Links from clipboard («Импортировать ссылки из буфера обмена»). Вместо меню можно нажать Ctrl+V в главном окне v2rayN.
  4. Выберите вкладку All, чтобы увидеть добавленное подключение. Найдите новую строку Connection и сделайте её активной: нажмите Enter или дважды щёлкните по строке. При импорте прямой ссылки добавляется одно подключение.
  5. Внизу окна в меню Routing выберите вариант с (Global). Включите переключатель Enable Tun. Подтвердите запрос Windows, если он появится. Приложение должно быть запущено от имени администратора.
  6. Откройте сайт в браузере и проверьте доступ к интернету. После замены сервера заново скопируйте прямую ссылку из кабинета и импортируйте её этим же способом. Старая прямая ссылка сама не обновляется.
