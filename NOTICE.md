# Происхождение и сторонние компоненты

ASMove VPN — самостоятельная выборочная производная авторского проекта
кабинета доступа. 24.11.2026 владелец исходного проекта подтвердил, что создал
его с нуля и владеет правами. Для этого публичного проекта выбрана MIT.
Имя владельца не выдумано; строку copyright можно дополнить публичным именем.
Исходная история Git и материалы пользователей не перенесены.

[Манифест импорта](docs/import-manifest.json) содержит исходную ревизию и SHA256
отобранных файлов до изменений. Это сведения о происхождении, не заявление
о том, что исходные версии были публичными или уже распространялись под MIT.

| Компонент | Как используется | Лицензия / источник |
| --- | --- | --- |
| 3x-ui v3.11.0 | Установщик загружает релиз отдельно; бинарников в Git нет | [GPL-3.0](https://github.com/MHSanaei/3x-ui/blob/main/LICENSE) |
| Xray-core | Берётся из поставки 3x-ui для EU и наблюдателя | [MPL-2.0](https://github.com/XTLS/Xray-core/blob/main/LICENSE) |
| Certbot 5.4.0 | Отдельное окружение RU | [Apache-2.0](https://github.com/certbot/certbot/blob/main/LICENSE.txt) |
| acme.sh 3.1.7 | Загрузка проверенного исходника для сертификата EU | [GPL-3.0](https://github.com/acmesh-official/acme.sh/blob/master/LICENSE.md) |
| FastAPI / Uvicorn / Jinja2 | Python-пакеты через pip | MIT / BSD-3-Clause / BSD-3-Clause, см. metadata пакетов |
| argon2-cffi / cryptography | Хэши и шифрование кодов | MIT / Apache-2.0 или BSD-3-Clause, см. metadata пакетов |
| Python-Markdown | Только локальная сборка документации | [BSD-3-Clause](https://github.com/Python-Markdown/markdown/blob/master/LICENSE.md) |

Это не перелицензирование сторонних компонентов. При отдельном распространении
их бинарников необходимо приложить их уведомления, лицензии и исполнить условия
предоставления исходников. Полный список транзитивных пакетов фиксируют constraints;
`python -m pip inspect` показывает установленный состав. Скриншоты и шрифты третьих
лиц не включены. Демонстрационная карточка и SVG созданы заново.
